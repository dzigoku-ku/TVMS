# Резервирование радиорелейной линии

Распределение резервных станций по интервалам радиорелейной линии. Надёжность линии максимизируется методом динамического программирования при ограничении на суммарную стоимость. Это расчётная схема примера 2 лекции по динамическому программированию.

Запуск:

```bash
python3 main.py
```

Нужен Python 3 со стандартным `tkinter`. Если окна нет и импорт падает, на Debian/Ubuntu пакет называется `python3-tk`.

Проверка формул и примера лекции без окна:

```bash
python3 model.py
```

При старте подставлен пример лекции: три интервала, бюджет 1200 у.е., не больше двух резервных станций на интервал. Кнопка «Пример из лекции» возвращает эти данные.

## Модель

На интервале одна рабочая станция и `x` резервных. Вероятность безотказной работы одной станции равна `p`, отказы станций на интервале независимы:

```text
P(x) = 1 − (1 − p)^(1 + x)
```

Стоимость интервала включает рабочую станцию и резерв:

```text
C(x) = (1 + x) · c
```

Отказы разных интервалов независимы, поэтому вероятность безотказной работы линии равна произведению `P(x)`. Сумма `C(x)` не должна превысить бюджет. Число `x` целое, от 0 до выбранного максимума.

В примере лекции:

| Интервал | p одной станции | c, у.е. | x = 0 | x = 1 | x = 2 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0,70 | 100 | 0,70 / 100 | 0,91 / 200 | 0,973 / 300 |
| 2 | 0,60 | 200 | 0,60 / 200 | 0,84 / 400 | 0,936 / 600 |
| 3 | 0,50 | 300 | 0,50 / 300 | 0,75 / 600 | 0,875 / 900 |

## Как считается

Обратная прогонка. Состояние `s` — деньги, выделенные на текущий и следующие интервалы. Шаг сетки — наибольший общий делитель стоимостей и бюджета. В примере это 100 у.е.

На последнем интервале для каждого допустимого `s` выбирается `x` с наибольшей `P(x)`, если стоимость варианта не выше `s`. На предыдущем интервале значение варианта равно `P(x)`, умноженной на уже посчитанный оптимум остатка `s − C(x)`.

Сначала строятся таблицы условных решений. Затем от полного бюджета программа идёт к концу линии и по остатку снимает безусловное `x`.

Для примера лекции план такой: `x* = {1, 1, 1}`. Вероятность линии `0,91 · 0,84 · 0,75 = 0,5733`. Затраты `200 + 400 + 600 = 1200` у.е.

В таблице лекции для остатка 800 у.е. на втором интервале выбран вариант `x = 1` со значением 0,42. По уравнению Беллмана при этом остатке лучше `x = 0` со значением 0,45: `0,6 · 0,75 = 0,45`. Программа оставляет этот максимум. На план `{1, 1, 1}` строка 800 не влияет: до неё оптимальный путь не доходит.

Менять можно бюджет, потолок резерва и состав линии: до 8 интервалов, вероятность и стоимость станции на каждом. Стоимости и бюджет задаются целыми у.е.
